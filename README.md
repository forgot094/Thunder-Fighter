# 🚀 雷霆战机 (Thunder Fighter)

A classic shoot-em-up game built with C++ and Raylib.

这是一个使用 C++ 和 Raylib 图形库开发的 2D 飞行射击游戏。使用 Visual Studio 2026 构建。

## 🎮 玩法
- **方向键**：移动战机
- **空格键**：发射子弹
- **道具系统**：击杀敌机有概率掉落道具（🟩 绿色方块回血，🟨 黄色圆圈火力升级）。
- **变化难度**：击杀敌机获得积分，敌机飞行速度随积分增加而加快，生成速度也回加快。
- **史诗 Boss 战**：达到一定分数会触发 Boss 战！击败 Boss 可获得回血，并且重新刷新敌人的强度。

## 🛠️ 技术栈
- 语言：C++
- 图形与音频库：Raylib
- 开发工具：Visual Studio 2026
